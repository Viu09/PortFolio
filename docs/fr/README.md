# Documentation (FR)

Bienvenue dans la documentation du portfolio. Voici un plan rapide des fichiers disponibles.

## Liens rapides
- `docs/fr/DEVELOPER.md` : guide developpeur (installation, commandes, structure)
- `docs/fr/ARCHITECTURE.md` : architecture et choix techniques
- `docs/fr/USER_GUIDE.md` : guide utilisateur
- `docs/fr/TESTING.md` : execution des tests et bonnes pratiques
- `docs/fr/TEST_REPORT.md` : couverture detaillee des tests

## Rapports de tests
- Rapport d'execution genere apres les tests : `tests/TEST_REPORT.md`
- Log brut des tests : `tests/test-output.log`

## Notes
- Les fichiers a la racine de `docs/` sont des index qui pointent vers les versions FR/EN.
- Pour mettre a jour le contenu, privilegier les fichiers dans `docs/fr/` et `docs/en/`.
