# Guide utilisateur

## Navigation
- Utiliser la barre du haut pour acceder aux sections.
- Les ancres menent directement a la section souhaitee.

## Langue
- Le bouton de langue permet de basculer a tout moment.
- Le choix reste actif tant que l'onglet est ouvert.

## Projets
- Chaque carte propose "Voir le projet" et "Voir le code".
- La page projet detaille le contexte, l'approche, la documentation et la video.

## Pages projet
- Une navigation interne permet d'aller aux sections cles.
- Les boutons precedent/suivant permettent d'enchainer les projets.

## Contact
- Le bouton Email ouvre le client mail.
- Les boutons GitHub et LinkedIn ouvrent les profils.
