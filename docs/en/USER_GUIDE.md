# User Guide

## Navigation
- Use the top bar to jump to each section.
- Anchor links take you directly to the target section.

## Language
- The language toggle lets you switch at any time.
- The selection stays active while the tab is open.

## Projects
- Each card offers "View project" and "View code".
- The project page details context, approach, documentation, and video.

## Project pages
- Internal navigation helps jump to key sections.
- Previous/next buttons let you browse projects quickly.

## Contact
- The Email button opens your mail client.
- GitHub and LinkedIn buttons open the profiles.
